# Integra GUI для Zapret

> Я не являюсь разработчиком Zapret и не представляю его авторов. Этот проект содержит только графический интерфейс (GUI) для управления отдельной установкой Zapret.

Integra помогает выбрать и запустить стратегию Zapret, управлять списками доменов, проверить доступность сайтов, настроить службу и подключить браузерное расширение. Компоненты Zapret, `winws.exe`, WinDivert и стратегии не входят в этот репозиторий.

## Запуск готовой программы

1. Откройте `Integra/Integra.exe`.
2. Подтвердите запрос UAC: для запуска и остановки `winws.exe` нужны права администратора.
3. На первом запуске откройте **Настройки -> Обслуживание Zapret**. Включите установку при отсутствии, либо вручную укажите папку уже установленного Zapret.
4. Для ручной установки выберите папку, в которой есть `general*.bat`, `bin/winws.exe` (или `winws.exe`) и `lists`.

Поддерживаются Windows 10/11 x64 и ARM64. Для готовой сборки Python не требуется.

## Как пользоваться

На странице **Главная** выберите стратегию из найденных `general*.bat` и нажмите запуск. Integra показывает состояние процесса, его PID и позволяет остановить его. В разделе настроек можно установить Zapret как службу и настроить автозапуск GUI.

Раздел **Списки** редактирует домены и IP/CIDR в списках установленного Zapret. Изменения обычно применяются после перезапуска стратегии или службы.

В **Диагностике** можно проверить встроенные или свои адреса через DNS и TCP-подключение, а также запустить подбор стратегии. Это измерение доступности TCP, а не ICMP ping; результат зависит от сети и не гарантирует одинаковую работу у всех провайдеров.

## Браузерное расширение

Расширение находится в `/Integra/browser-extension` для готовой программы и для разработки. Оно работает в Chrome, Edge, Brave, Opera и других Chromium-браузерах.

1. Запустите Integra и откройте раздел **Расширение**.
2. В браузере откройте страницу управления расширениями и включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите папку `browser-extension` из `app/Integra`.
4. Откройте расширение и введите код привязки, показанный в Integra.

После привязки расширение может добавлять текущий домен в списки, удалять его из списков и показывать TCP-задержку. Оно обращается к локальному мосту Integra на `127.0.0.1`; внешние серверы для этой связи не используются.

## Как это работает

Integra не изменяет исходные `general*.bat` Zapret. Для выбранной стратегии она создаёт временный служебный BAT-файл, запускает его скрыто и отслеживает процесс `winws.exe`. Настройки программы хранятся отдельно в профиле пользователя Windows.

При включённом обслуживании программа проверяет официальный релиз Zapret, может установить его в `%LOCALAPPDATA%\Integra\zapret` и безопасно обновить с сохранением папки `lists`. Перед обновлением она не заменяет работающую установку или установку со службой.

## Запуск исходников и сборка

Откройте консоль в `code` и запустите `run.bat`. Скрипт при необходимости установит 64-битный Python 3.10-3.14, создаст `code/.venv` и установит зависимости.

Для проверки исходников выполните `test.bat`. Для сборки выполните `build.bat`; результат будет создан или обновлён в `app/Integra`.

Эквивалентные команды:

```bat
cd code
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe scripts\check_project.py
.venv\Scripts\python.exe scripts\build_app.py --arch x64
```

## Если не запускается

- Проверьте, что программа запущена от имени администратора.
- Проверьте путь к Zapret: в нём должны быть `general*.bat` и `winws.exe`.
- Если `winws.exe` исчез, проверьте карантин антивируса и целостность своей установки Zapret.
- Не переносите один `Integra.exe` отдельно от содержимого `app/Integra`.
